# DITA Bootstrap Offline Mode

This is a sample DITA-OT plug-in that bundles all the necessary Bootstrap CSS and JavaScript locally into the generated HTML output as described in the DITA Bootstrap plug-in documentation under [Offline Mode](https://dita-bootstrap.org/html/offline.html).

> [!IMPORTANT]  
> Requires the [dita-bootstrap.html](https://github.com/dita-bootstrap.html) plug-in for DITA Open Toolkit.  
> For details, see [dita-bootstrap.org](https://dita-bootstrap.org/html/).
